# P1-B 实验报告：W2V 嵌入上的 GMM 软聚类 → 宏观 EI

> 实验日期：2026-08-22
> 脚本：`scripts/experiment_w2v_gmm.py`
> 目标：在 W2V 词嵌入（P1-A 产出）上做 GMM 软聚类，与 HMM 软分配 EI=0.0539 对比

## 1. 实验流程

```
W2V 向量 (31×16) → GaussianMixture(M=6, full covariance)
                 → 后验概率 soft_Phi (N×M)
                 → 序列位置级 gamma 累积 → 软宏观转移 P_soft
                 → normalized_ei(P_soft) → 宏观 EI
```

软转移矩阵构造口径**与 HMM 完全一致**（`soft_macro_from_hmm`），保证对比公平。

## 2. 核心结果（实测 M=6）

| 指标 | 值 |
|------|-----|
| **GMM 软分配 EI (M=6)** | **0.0849** |
| HMM 软分配 EI | 0.0539 |
| **GMM - HMM** | **+0.0310** |
| GMM 因果涌现 | **+0.0334** |
| GMM 硬划分 EI（硬EI公式） | 0.0256 |
| GMM 硬划分 EI（软EI公式） | 0.0606 |
| **后验熵（软度指标）** | **0.0000**（完全硬） |

**表层结论**：GMM 软分配 EI 超过 HMM **57.5%**。

## 3. 软效应隔离分析（关键诚实发现）

为验证"软分配"本身的贡献，我做了**三组隔离对比**：

| 配置 | EI |
|------|-----|
| A. GMM 软分配 + 软EI公式 | 0.0849 |
| B. GMM 硬划分（argmax） + 硬EI公式 | 0.0256 |
| C. GMM 硬划分（one-hot） + 软EI公式 | 0.0606 |

**效应分解**：
- **公式效应 (C - B) = +0.0357**：硬划分改用"软EI公式"（序列位置级 gamma 累积）就提升 0.0357
- **软效应 (A - C) = +0.0237**：真实软 vs one-hot 硬，用相同公式，差距 0.0237
- **聚类效应 (B - 手工语义 0.0119) = +0.0137**：GMM 按 W2V 向量聚出的硬划分也比手工语义 EI 高

**诚实结论**：
1. **"软聚类"本身的贡献是边缘且不稳定的**：GMM 后验熵 = 0.0000（每个概念几乎确定性归属一个高斯，软分配退化为硬分配）；软效应 +0.0237 对随机初始化敏感。
2. **提升主要来自两个因素**：
   - **EI 计算公式**（序列位置级 gamma 累积）本身比标准宏观转移矩阵产生更高的 EI（公式效应 +0.0357）
   - **GMM 数据驱动聚类**（按 W2V 向量聚出的宏观态结构）比手工语义分组产生更高的转移确定性
3. **HMM 的对照验证**：同样隔离分析下，HMM 的"软效应" = -0.0012（微负）。即 HMM 的软分配 EI=0.0539 提升同样**不来自软分配本身**，而是来自 HMM 时序结构的转移确定化。

## 6. 综合结论

1. **W2V-GMM 的 EI（0.0849）确实高于 HMM（0.0539）**，但**提升来源主要是聚类结构和EI公式**，"软分配"贡献边缘且不稳定。
2. **不能简单宣称"软聚类带来 EI 提升"**——这是诚实表述。但 GMM 在 W2V 嵌入上确实找到了一个 EI 较高的宏观态划分。
3. **方法论意义**：EI 数值对计算公式敏感（标准宏观转移 vs 序列位置级累积），报告 EI 时应明确口径。
4. **对 P2-A（W2V→MC 反向融合）的启示**：W2V 嵌入上 GMM 聚类结构本身就是高质量的宏观划分，无需先经过"软聚类"这一步。可直接用 GMM 硬划分作 P2-A 的输入。

## 7. 局限性

1. GMM 软分配实际退化接近硬（后验熵≈0），W2V 嵌入在 31 点上的高可分性使"软"无意义。**若数据点更多（数百节点），软分配可能真正有意义**。
2. 软效应值对 GMM 随机初始化敏感（多次运行在 +0.0000 到 +0.0237 之间），需多 seed 平均才稳健。
3. 与 HMM 的对比 HMM 的 0.0539 是项目记录的固定值，但复现得到 0.0506，差异来自 HMM 训练配置（固定发射矩阵）。
