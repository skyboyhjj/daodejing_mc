# 马尔科夫链 × Word2Vec 融合实验说明书

## 1. 理论背景

马尔科夫链（MC）描述概念间的转移概率 P；词向量（W2V）通过共现统计学习分布式表示。
两者的数学桥梁是 PMI 矩阵：

    PMI(w_i, w_j) = log( F_ij / (π_i · π_j) )
    其中 F = diag(π) @ P 是稳态流矩阵

Word2Vec Skip-gram 的本质是对移位 PMI 矩阵做矩阵分解（Levy & Goldberg 2014）。
因此：SVD of F ≈ Word2Vec on random walks。我们对 F 做 SVD 得到的谱空间散点图，本质上就是 LSA 词向量。

## 2. 实验 A：MC → W2V（单向融合 / DeepWalk 范式）

### 流程
1. 加载已保存的 output/P_matrix.npy（31×31 转移矩阵）
2. 以 P 为转移概率做马尔科夫链随机游走，生成 10000 条长度为 20 的序列
3. 用 gensim Word2Vec (sg=1, window=3, vector_size=16) 训练
4. 得到每个概念的 16 维动态词向量

### 预期输出
- output/w2v_vectors.npy：31×16 向量矩阵
- output/w2v_similarity.csv：31×31 余弦相似度矩阵
- 控制台输出：W2V 嵌入与 SVD 嵌入的 Kendall τ 相关系数

### 解读标准
| τ 值 | 解读 |
|------|------|
| > 0.6 | 概念结构高度自洽：全局谱结构与局部随机游走一致 |
| 0.3 ~ 0.6 | 中等一致：大部分概念自洽，少数概念"表里不一" |
| < 0.3 | 不一致：老子写作中存在非线性跳跃（对应"正言若反"）|

## 3. 实验 B：W2V → MC（反向融合 / 图传播）

### 流程
1. 用语义先验（如随机初始化或 BERT）得到概念初始向量 E0 (31×16)
2. 用转移矩阵 P 做图传播（类似 DeepWalk 但反向）：
   E_t = α·E0 + (1-α)·P^T·E_{t-1}
3. 收敛后得到"动力学感知的词向量"
4. 在 E_final 上做 K-Means (M=6)，计算成块性 ε

### 预期
- 如果 ε < 0.00516（纯 SVD 的结果），说明加入语义先验后分组更优
- 如果 ε 变大，说明语义先验与转移动力学冲突（如"无"在语义上近"道"，但动力学上近"无为"）

## 4. 评估指标汇总

| 指标 | 来源 | 用途 |
|------|------|------|
| Kendall τ | W2V相似度 vs SVD相似度 | 结构自洽性 |
| 成块性 ε | 宏观划分 | 粗粒化合法性 |
| EI_norm | 有效信息 | 因果涌现 |
| 解释方差 | SVD | 降维充分性 |
