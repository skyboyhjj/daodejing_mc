# P2-A 实验报告：W2V → MC 反向融合（图传播）

> 实验日期：2026-08-22
> 脚本：`scripts/experiment_w2v_mc_back.py`
> 目标：验证用 W2V 作为语义先验，通过图传播是否提升 K-Means 分组的成块性 ε

## 1. 实验流程

```
W2V 向量 (31×16) → 语义先验 E0
             ↓
图传播：E_new = α·E0 + (1-α)·P^T·E_old  （迭代至收敛）
             ↓
K-Means(M=6)  →  分组标签
             ↓
lumpability_error(P, partition, idx)  →  成块性 ε
```

扫描 α ∈ {0.0, 0.2, ..., 1.0}，观察语义-动力学混合比例对分组自洽性的影响。

### 2.2 α 扫描曲线（vis_12_w2v_mc_back.png 左图）

ε 随 α 的变化不单调，呈现复杂曲线：
- **α ∈ [0.0, 0.3]**：ε 稳定在 0.002~0.003（动力学主导，ε 较低）
- **α ≈ 0.4~0.5**：ε 出现第一个峰值 ~0.008~0.005
- **α ≈ 0.7**：ε 达到最高 0.013（语义开始占主导，与动力学冲突）
- **α ∈ [0.8, 1.0]**：ε 回落到 0.006~0.008（纯 W2V 语义）

## 3. 关键发现

### 3.1 TODO P2-A 假设被反驳

TODO P2-A 的假设："如果 ε < 0.00516（纯 SVD 的结果），说明加入语义先验后分组更优；如果 ε 变大，说明语义先验与转移动力学冲突。"

**实测结论**：加入 W2V 语义先验**确实与转移动力学冲突**——ε 在 α>0.3 后整体上升，纯 W2V (α=1.0) ε=0.0064 是最差结果。

### 3.2 纯动力学/SVD 才是最优

- **纯 SVD(16d)** ε=0.0017 最优（比手工语义 0.0046 低 63%）
- 这说明《道德经》概念的"成块性"主要由**全局转移模式**（SVD 谱）刻画，而非局部共现（W2V 随机游走）
- 与 P1-A 的发现（τ=0.198，W2V 与 SVD 结构低相关）一致：W2V 与 SVD 捕捉的是概念空间的不同结构

### 3.3 W2V 的语义先验为何冲突？

W2V 由 Skip-gram 在随机游走序列上训练，捕捉**局部共现统计**（PMI 矩阵分解）。但 P 的"成块性"要求**全局转移概率**在同一块内一致。两者不匹配是因为：

- "无"在语义上近"道"（核心-本体），但动力学上近"无为""无有"
- "水"在语义上独立，但在动力学上接近"柔弱"（上善若水）
- 这种"语义 vs 动力学"不一致，正是老子"正言若反"的具体体现

## 4. 方法论启示

1. **对 P2-A 原假设的修正**：W2V 语义先验在此数据上**未带来改善**。语义先验适合"语义聚类"任务（节点分类），但成块性 ε 需要**全局动力学一致性**，语义与动力学结构不同。
2. **跨任务指标差异**：P1-A 链接预测 W2V 更强（局部共现预测转移），但 P2-A 成块性 W2V 更弱（局部共现破坏全局成块性）。**同一嵌入在不同任务上表现不同**。
3. **纯 SVD 是最优宏观结构**：对于"动力学感知的宏观态分组"任务，纯 SVD 谱嵌入 + K-Means 是最佳方法，无需 W2V 先验。
