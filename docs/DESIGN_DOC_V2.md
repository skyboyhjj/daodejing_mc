### 核心发现（修正原方案的关键认知）

> **《道德经》的马尔科夫链建模揭示了一个反直觉事实：粗粒化不涌现。**

原方案预期"粗粒化后 EI 会跃升"，实测结果是**所有 M>1 的方案 EI 都低于微观基线**。这说明：

1. **《道德经》的概念动力学本身就是"扁平"的**——没有清晰的层级结构让粗粒化去发现
2. **老子刻意使用的"循环论证"风格**（道→无→有→道）导致转移矩阵接近均匀混合，EI 天然偏低
3. **成块性误差很小（ε=0.005）但 EI 不升**——说明分组在"流量守恒"上自洽，但**不增加可预测性**

这不是失败，而是对文本本质的诚实刻画。

## 三、对原方案的关键修正

### 修正1：k=2 不能用于主分析

| 原方案假设 | 实测结果 | 修正 |
|---|---|---|
| k=2 可能捕捉到"无为+而治"等二元语法 | k=2 联合状态39个，密度仅2.96% | **k=2 仅作对照，主分析用 k=1** |
| 可以通过滑动窗口扩充 k=2 样本 | 未验证 | 下一步可尝试 n-gram 扩充 |

**根因**：《道德经》仅849个概念观测，支撑不了39个联合状态（需要约780次有效观测，实际仅45次）。

### 修正2：因果涌现不存在

| 原方案假设 | 实测结果 | 修正 |
|---|---|---|
| 粗粒化后 EI 可能跃升，发生因果涌现 | 所有 M 的宏观 EI 都 < 微观 EI | **放弃"涌现"叙事，转向"结构自洽性"叙事** |
| EI 最大化 = 最优读解 | EI 最大化给出 M≈2-3（太粗） | **改用成块性 ε + 语义可解释性 作为选M标准** |

**哲学含义**：老子思想的"道可道非常道"在马尔科夫意义上意味着——**概念转移本身就是不可压缩的**。你无法用更少的宏观态来无损地压缩这五千言的动力学。这恰好印证了"道不可言说"的本体论立场。

### 修正3：聚类质量普遍偏低

| 原方案假设 | 实测结果 | 修正 |
|---|---|---|
| SVD 嵌入 + K-Means 能给出清晰分组 | silhouette ~0.1-0.2（接近随机） | **SVD 第一奇异值主导，投影近似一维** |
| K-Means 是首选聚类算法 | 在近似一维数据上 K-Means 效果差 | **改用 Ward 层次聚类（对一维数据更鲁棒）** |
| 数据驱动分组应优于手工分组 | 手工语义分组 ε=0.005，K-Means ε 更大 | **以手工语义分组为主结果，数据驱动为对照** |

### 修正4：新增"数据充分性诊断"为必做步骤

原方案没有这一步，导致早期用3章文本跑 k=2 时产生了误导性结果（密度13.49%看似合理，实际是 Laplace +1 平滑造成的假象）。

**修正后的诊断流程**（已验证）：
```python
# Step 1: 看原始计数矩阵（不是平滑后的！）
density = (C > 0).sum() / C.size  # k=1: 35.1% ✓; k=2: 2.96% ✗

# Step 2: 平均每对观测
avg_obs = C.sum() / max((C > 0).sum(), 1)  # k=1: ~3.5 ✓

# Step 3: 单目标行数（只转移到一个地方的状态数）
single_target = (C.sum(axis=1) == 1).sum()  # 多则说明数据稀疏

# 判据：density > 15% 且 avg_obs > 5 → 可靠
```

## 六、核心方法论原则（从实测中提炼）

### 原则1：先看数据充分性，再建模型
> 不要相信平滑后的矩阵密度。**永远用原始计数矩阵 C 做诊断**。Laplace +1 会掩盖稀疏性。

### 原则2：微观基线是铁律
> 任何粗粒化方案都必须和微观 EI 比较。**如果所有 M 的 EI 都低于微观基线，说明文本本身不适合粗粒化**——这不是算法的问题，是文本的性质。

### 原则3：可解释性优先于指标最优
> 当 K-Means 的 silhouette 最高分组把"道"和"兵"放在一起时，这个"最优"毫无意义。**手工语义分组虽然 EI 不是最高，但每个分组都能用老子自己的话解释**——这才是深度读解想要的。

### 原则4：成块性 ε 比 EI 更适合选 M
> EI 衡量"可预测性"，成块性 ε 衡量"分组自洽性"。对《道德经》这种哲学文本，**自洽性比可预测性更重要**——我们想知道"哪些概念属于同一个义理模块"，而不是"能多准确地预测下一个概念"。

### 原则5：负结果也是结果
> "《道德经》的马尔科夫链粗粒化不涌现"本身就是一个有意义的发现。它用信息论的语言重新表述了"道可道非常道"——**道的动力学是不可压缩的**。
