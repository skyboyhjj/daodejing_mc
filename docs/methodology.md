# 《道德经》马尔科夫链建模 — 方法论说明

> 本文件系统说明项目的数学方法、建模假设与结果解读，供复现与扩展参考。
> 所有数值为 T13 修复 REVERSE_MAP bug 后的最终实测值（2026-08-21）。

---

## 1. 总体思路

《道德经》81 章由约 849 次概念观测构成。我们把**概念序列**视为一个离散时间马尔科夫链：当前概念只依赖上一个概念（一阶），转移概率编码了"道→德→无→有→道"这类概念间的牵引关系。

完整 Pipeline：

```
文本清洗 → 概念抽取 → 转移矩阵 P → 平稳分布 π
     ↓
EI 计算（微观基线）→ 粗粒化（多方案）→ 宏观转移矩阵 P_macro
     ↓
宏观 EI → 因果涌现 → 成块性检验 → 结构诊断（可逆性/混合时间/中心性）
     ↓
6+ 种可视化 + Word 报告
```

## 2. 数据预处理

### 2.1 文本清洗

原文本逐章保留，仅去除标点、引号与空白。为稳健处理中文标点（避免引号提前终止字符串等编码陷阱），采用 **Unicode 范围白名单**：

```python
re.sub(r'[^\u4e00-\u9fff0-9A-Za-z]', '', text)
```

只保留 CJK 汉字（U+4E00–U+9FFF）与数字字母。

### 2.2 概念抽取

用**最长优先匹配 + 单字回退**从清洗后的文本中抽取标准化概念：

1. 先尝试 4/3/2 字变体匹配（如"上善若水"→"水"、"小国寡民"→"小国寡民"）。
2. 匹配失败则单字回退（如"道"）。

概念词典 `CONCEPT_DICT` 将文本变体映射到 31 个标准化概念（道、德、无、有、无为、自然……）。

> ⚠️ **T13 修复的关键 bug**：构建反向映射 `REVERSE_MAP` 时，同一变体可能被多个标准概念收录（如"无为"同时属于"无"与"无为"）。**冲突时优先更长（更具体）的标准概念**，避免"无为"被错误归入"无"。修复后"无"87→78 次、"无为"31→43 次。

## 3. 马尔科夫链建模

### 3.1 转移矩阵

对概念序列 `{c_1, ..., c_T}`，一阶转移计数：

```
C[i, j] = #{ t : c_t = i, c_{t+1} = j }
```

用 Laplace 平滑得到行随机矩阵：

```
P[i, j] = (C[i, j] + α) / Σ_k (C[i, k] + α)     (α = 1.0)
```

满足行和恒为 1。k=2 时构建联合态 `(c_t, c_{t+1})` 到 `(c_{t+1}, c_{t+2})` 的**方阵**（否则无法求平稳分布）。

### 3.2 平稳分布

用幂迭代求 `πP = π, Σπ = 1`。π 表示长期来看各概念出现的比例（如"民"0.074、"无"0.060）。

---

## 4. 有效信息 EI

### 4.1 定义

有效信息度量转移矩阵的"因果确定性程度"：

```
EI(P) = Σ_i π_i · D_KL(P_i || P_bar)
```

其中 `P_bar = πP` 是"平均效应"分布。直觉：若每行转移都高度集中在特定目标（确定性高），EI 大；若各行都均匀，EI=0。

### 4.2 归一化

```
EI_norm = EI / log(N)
```

取值 [0, 1]。确定性置换矩阵 EI_norm = 1，均匀矩阵 EI_norm = 0。

### 4.3 已知解析结果（用于单元测试）

- 均匀矩阵：EI = 0（无因果效应）。
- 确定性置换：EI = log(N)（信息最大）。
- 单状态矩阵：EI = 0。

## 5. 粗粒化

粗粒化将 N 个微观概念映射到 M 个宏观块，考察是否涌现更强的因果结构。

### 5.1 分组方案对比

| 方案 | 说明 |
|------|------|
| **手工语义**（采用） | 基于义理结构：道体论/无为法/辩证法/治术/民知欲/宇宙，M=6，可解释性最优 |
| Ward 层次聚类 | 在 P 行空间 + 频率向量上聚类 |
| SVD + K-Means | 对 F=diag(π)P 的右奇异向量做 K-Means |

### 5.2 宏观转移矩阵

给定分组标签，用投影矩阵 Φ（N×M，硬划分独热）构建：

```
P_macro = normalize(Φᵀ P Φ)
```

### 5.3 因果涌现

```
因果涌现 = EI_norm(P_macro) − EI_norm(P)
```

**实测为负（-0.0397）**，说明宏观化不增加可预测性。详见"结果解读"。

---

## 6. 结构诊断

### 6.1 成块性检验

对每个块 B 与目标块 C，比较从 B 内不同概念出发到 C 的转移概率是否一致（成块 = 一致）：

```
ε = max_{B,C} Var_{i∈B}( P[i → C] )
```

实测 ε = 0.005，远小于阈值 0.01 → 分组在"流量守恒"意义上近似成块。

### 6.2 时间可逆性

稳态流矩阵 `F = diag(π) P`。若 F = Fᵀ（细致平衡），则链时间可逆。实测相对偏差 0.41 → **弱不可逆**，概念流动有明显方向性。

### 6.3 混合时间

```
τ_mix = 1 / (1 − |λ₂|)
```

λ₂ 为 P 第二大特征值绝对值。实测 λ₂ = 0.27，τ_mix = 1.38 → 极快混合，概念动力学迅速收敛。

### 6.4 随机游走中心性

- **PageRank**：带阻尼的中心性，识别枢纽概念（民 > 无 > 道 > 有 > 知）。
- **命中时间**：从任意概念到达目标概念的平均步数（水/自然/朴 最短，最易达）。
- **覆盖时间**：从起点访问全部 31 概念所需步数（平均 185 步，蒙特卡洛）。

## 7. 结果解读

### 7.1 为什么粗粒化不涌现？

这是本项目最反直觉的发现。三种可能的解释：

1. **动力学本身扁平**：《道德经》概念转移接近均匀混合（密度 35%、λ₂ 小），没有清晰的层级结构供粗粒化发现。
2. **循环论证风格**："道→无→有→道"的循环使转移矩阵各行相似，EI 天然偏低，宏观化进一步稀释信息。
3. **成块但不涌现**：分组在流量守恒上自洽（ε 很小），但不增加可预测性——"道可道，非常道"的信息论表达。

### 7.2 HMM 软分配为何更好？

固定发射矩阵（=硬划分的软化）后，HMM 软分配 EI = 0.0539 **高于微观 0.0515**。原因：软分配保留概念在多个宏观态之间的后验权重，不损失时间序信息。31/31 概念软分配 MLE 标签与硬划分完全一致，说明语义结构是稳健的。

### 7.3 哲学意涵

> **"道可道，非常道" = 概念动力学不可压缩。**

宏观粗粒化无法无损重构五千言的转移结构——道在最微观层面已经是最经济的描述。这为"道不可言说"提供了一种信息论解读。

## 8. 局限性

| 局限 | 说明 | 改进方向 |
|------|------|---------|
| 一阶假设 | 只考虑相邻转移 | 可扩展高阶/隐藏状态（已试 k=2，密度 0.6% 不足） |
| 词典覆盖 | 31 概念可能漏低频词 | 扩充至 50+ 或 TF-IDF 自动发现 |
| 句子级信息损失 | 一句多概念只取第一个 | 集合转移模型 |
| 单一版本 | 基于王弼本 | 帛书本/《庄子》跨文本对照 |
